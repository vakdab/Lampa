# Lampa Smooth Player

Легкий зовнішній плагін для Lampa, який робить відеоплеєр плавнішим і додає сучасні режими розміру кадру без перескладання Lampa.

## Що змінено

- прибрано WebGPU/AI-апскейлінг, який обробляв кожен кадр і міг викликати ривки;
- прибрано постійні CSS-фільтри, `will-change` та примусовий `preload=auto`;
- розмір відео застосовується через один `requestAnimationFrame`, без серії таймерів на 100/500/1200 мс;
- додано плавне реагування на зміну орієнтації та розміру екрана;
- мобільний патч використовує безпечні iPhone safe-area та не ламає вертикальні/горизонтальні свайпи;
- під час запуску активного відео автоматично ховаються шапка та нижня панель Lampa;
- після дотику до відео плагін пробує увімкнути стандартний fullscreen із прихованою навігацією;
- збережено меню **Налаштування плеєра → Розмір відео**.

## Встановлення Smooth Player

Рекомендований URL:

```text
https://cdn.jsdelivr.net/gh/vakdab/Lampa@main/lampa-combined-fix.js
```

Додайте його в Lampa через **Розширення → Додати плагін**. Не встановлюйте старі `lampa-ai-webgpu.js`, `player-size.js` та `lampa-mx-mobile-fix.js` одночасно — це може створити конфлікти стилів.

## AniSkip для iPhone

AniSkip — **окремий додатковий плагін**: він не замінює і не переписує Smooth Player. Для перевірки поточної iPhone-версії додайте цей URL у Lampa:

```text
https://cdn.jsdelivr.net/gh/vakdab/Lampa@ios-aniskip/lampa-aniskip.js
```

Після злиття змін до `main` стабільне посилання буде:

```text
https://cdn.jsdelivr.net/gh/vakdab/Lampa@main/lampa-aniskip.js
```

Плагін шукає MAL ID та номер серії з метаданих Lampa й звіряє назву через AniList, потім отримує часи пропуску з офіційного AniSkip API. У відео з’являється велика touch-кнопка **«Пропустити опенінг/ендинг»** у стилі напівпрозорих елементів плеєра. За замовчуванням потрібне натискання; автоматичний пропуск можна окремо ввімкнути в меню **AniSkip** поверх відео.

Якщо Lampa не передала точну назву чи номер епізоду, натисніть **AniSkip** і вкажіть назву, MAL ID та номер серії вручну. Доступність інтервалів залежить від наявності запису для конкретного аніме/епізоду в базі AniSkip. Якщо API недоступний або запис відсутній, відтворення не блокується і не перемотується. Плагін налаштовує `playsinline` на iPhone, щоб елементи керування сторінки могли лишатися поверх відео.

## Режими відео

- **Заповнити** — відео розтягується на всю висоту через `object-fit: fill`, із чорними полями по 2.5 мм зліва та справа;
- **Вмістити** — увесь кадр із чорними полями;
- **Збільшити 150/170/180%** — плавне масштабування центру кадру;
- **По вертикалі 150/170%** — збільшення по висоті;
- **Кіно 21:9** — відео на всю висоту через `object-fit: fill`, із чорними смугами по 8 мм зліва та справа.

За замовчуванням використовується режим **Вмістити**, щоб не розтягувати обличчя та не обрізати важливі частини кадру.

> Важливо для iPhone: біла смужка внизу на скриншоті — це системний Home Indicator iOS, а не елемент вебдодатка. Safari/PWA не дозволяє плагіну примусово сховати її в embedded-режимі. Плагін ховає інтерфейс Lampa та запитує справжній fullscreen після дотику; якщо iOS дозволяє fullscreen для поточного вебдодатка, системна панель зникає сама.
