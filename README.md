# Lampa WebGPU Video Enhancement

Чистий зовнішній плагін для Lampa, який додає одне покращення відео через **Anime4K-WebGPU**.

## Що є в плагіні

- один перемикач **«Покращення відео: Увімкнути / Вимкнути»** у меню якості плеєра;
- обробка відеокадрів на GPU пристрою через WebGPU;
- компактний режим CNNx2M для Anime4K;
- штатні відео та звук Lampa не замінюються;
- якщо WebGPU недоступний, відео залишається звичайним;
- якщо WebGPU повертає помилку або порожній кадр, плагін автоматично відключається;
- немає режимів Cinema, «Форма відео», старого WebGL Anime4K, AniSkip чи дубльованих меню.

## Встановлення

Додайте лише цей файл через **Розширення → Додати плагін**:

```text
https://cdn.jsdelivr.net/gh/vakdab/Lampa@main/lampa-combined-fix.js
```

Перед встановленням видаліть попередні копії `lampa-combined-fix.js`, `lampa-anime4k.js`, `anime4k-upscale.js` та інші старі плагіни покращення, щоб вони не перехоплювали один одного.

## Вимоги

Потрібен браузер або WebView із підтримкою WebGPU. WebGPU офіційно доступний у Safari 26 та iOS 26+, але фактична робота залежить від моделі iPhone і оболонки Lampa.

На старішій iOS плеєр працюватиме у штатному режимі без чорного екрана.
