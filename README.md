# Lampa Smooth Player

Легкий зовнішній плагін для Lampa, який робить відеоплеєр плавнішим і додає сучасні режими розміру кадру без перескладання Lampa.

## Що змінено

- прибрано WebGPU/AI-апскейлінг, який обробляв кожен кадр і міг викликати ривки;
- прибрано постійні CSS-фільтри, `will-change` та примусовий `preload=auto`;
- розмір відео застосовується через один `requestAnimationFrame`, без серії таймерів на 100/500/1200 мс;
- додано плавне реагування на зміну орієнтації та розміру екрана;
- Android TV не визначається як телефон лише через coarse-pointer; для нього не нав'язуються touch/inline/fullscreen патчі;
- прибрано примусове `backface-visibility` для відео, яке могло створювати зайвий шар композиції на слабких TV-пристроях;
- мобільний патч використовує безпечні iPhone safe-area та не ламає вертикальні/горизонтальні свайпи;
- під час запуску активного відео автоматично ховаються шапка та нижня панель Lampa;
- після дотику до відео плагін пробує увімкнути стандартний fullscreen із прихованою навігацією;
- збережено меню **Налаштування плеєра → Розмір відео**.

## Встановлення

Рекомендований єдиний URL:

```text
https://cdn.jsdelivr.net/gh/vakdab/Lampa@main/lampa-combined-fix.js
```

Додайте його в Lampa через **Розширення → Додати плагін**. Не встановлюйте старі `lampa-ai-webgpu.js`, `player-size.js` та `lampa-mx-mobile-fix.js` одночасно — це може створити конфлікти стилів.

## Режими відео

- **Заповнити** — відео розтягується на всю висоту через `object-fit: fill`, із чорними полями по 2.5 мм зліва та справа;
- **Вмістити** — увесь кадр із чорними полями;
- **Збільшити 150/170/180%** — плавне масштабування центру кадру;
- **По вертикалі 150/170%** — збільшення по висоті;
- **Кіно 21:9** — відео на всю висоту через `object-fit: fill`, із чорними смугами по 8 мм зліва та справа.

За замовчуванням використовується режим **Вмістити**, щоб не розтягувати обличчя та не обрізати важливі частини кадру.

## Android TV: помилки завантаження та кольори

На телевізорі встановлюйте лише рекомендований `lampa-combined-fix.js`; видаліть/вимкніть попередні копії цього або окремих legacy-плагінів, очистьте кеш плагінів і перезапустіть Lampa. На Android TV залишено керування відео самому Lampa/WebView: плагін не додає свій декодер і не примушує телефонний inline/fullscreen режим.

Повідомлення на кшталт `manifestLoadError` означає, що програвач не зміг завантажити HLS-плейлист `.m3u8`. Це зазвичай проблема конкретного джерела/посилання, сервера, мережі, CORS або простроченого токена, а не розміру кадру чи кольорів. Плагін не може відновити недоступний плейлист. Спробуйте інше джерело/якість того самого фільму та інший фільм; якщо помилка є лише в одного джерела — зверніться до його постачальника. Якщо не відкривається жодне джерело, перевірте дату й час телевізора, оновіть Android System WebView/систему та перевірте з'єднання через кабель або Wi‑Fi 5 GHz.

Плагін не змінює колірний профіль, HDR/SDR-перетворення чи Android-декодер — CSS-фільтри на всьому відео можуть лише спотворити кольори й додати навантаження. Для неприродних кольорів перевірте режим зображення телевізора (наприклад, «Кіно/Стандартний» замість «Динамічний»), вимкніть надмірне покращення кольору/шумозаглушення та перевірте той самий файл у системному відеоплеєрі. HDR залежить від можливостей телевізора, формату файла та джерела. Зовнішній Android-плеєр — окремий шлях від вбудованого Lampa; сам цей вебплагін не може перемкнути застосунок на Media3/ExoPlayer.

> Важливо для iPhone: біла смужка внизу на скриншоті — це системний Home Indicator iOS, а не елемент вебдодатка. Safari/PWA не дозволяє плагіну примусово сховати її в embedded-режимі. Плагін ховає інтерфейс Lampa та запитує справжній fullscreen після дотику; якщо iOS дозволяє fullscreen для поточного вебдодатка, системна панель зникає сама.
