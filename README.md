# Lampa Player Size

Зовнішній плагін для Lampa, який додає додаткові режими до меню **«Розмір відео»** без перескладання Lampa.

## Додані режими

- Збільшити 170%
- Збільшити 180%
- По вертикалі 170%
- По вертикалі 180%

## Встановлення

У Lampa відкрийте:

```text
Розширення → Додати плагін
```

і вставте URL:

```text
https://raw.githubusercontent.com/vakdab/Lampa/main/player-size.js
```

Після завантаження відкрийте плеєр і перейдіть у меню:

```text
Налаштування плеєра → Розмір відео
```

Плагін зберігає вибраний режим у сховищі Lampa та застосовує його до наступних відео.

## Додати інші режими

Режими знаходяться на початку `player-size.js` у масиві `customModes`. Наприклад:

```js
{
    value: 's200',
    title: 'Збільшити 200%',
    subtitle: 'Збільшити відео на 200%',
    sx: 2.00,
    sy: 2.00
}
```
