# Lampa Smooth Player

Легкий зовнішній плагін для Lampa, який робить відеоплеєр плавнішим і додає сучасні режими розміру кадру без перескладання Lampa.

## Що змінено

- додано реальний Anime4K WebGL апскейл x2 на GPU з автоматичним fallback на штатне відео;
- прибрано постійні CSS-фільтри, `will-change` та примусовий `preload=auto`;
- розмір відео застосовується через один `requestAnimationFrame`, без серії таймерів на 100/500/1200 мс;
- додано плавне реагування на зміну орієнтації та розміру екрана;
- мобільний патч зберігає безпечні iPhone safe-area, вільне гортання списків і закриття меню поза панеллю; він не додає observer до DOM, не змінює `<video>` та не викликає fullscreen;
- ліва панель меню закривається після короткого дотику поза її межами, не перериваючи вибір пунктів меню чи свайп;
- плагін не змінює `preload`, кешування або відновлення позиції відео Lampa;
- увімкнено легке апаратно-сумісне згладжування з інтенсивністю **4x** за замовчуванням без WebGPU-моделі та блокування старту плеєра;
- кнопка пропуску опенінга піднімається над нижньою чорною смугою та враховує safe-area: вище при закритому оверлеї й узгоджено з панеллю при відкритому;
- AniSkip знаходить опенінг за MAL ID та номером епізоду й показує кнопку ручного пропуску лише під час опенінгу;
- збережено меню **Налаштування плеєра → Розмір відео**.
- у меню **… → Якість** доступні **Anime4K x2** та **Вимкнути Anime4K**;
- у меню **…** додано пункт **Форма відео**, де доступний режим **Кіно 21:9** та інші режими кадру;

## Встановлення

Рекомендований єдиний URL:

```text
https://cdn.jsdelivr.net/gh/vakdab/Lampa@main/lampa-combined-fix.js
```

Додайте лише цей файл у Lampa через **Розширення → Додати плагін**. Він містить мобільний патч, керування розміром відео, реальний Anime4K WebGL та AniSkip.

Перед встановленням видаліть зі списку розширень попередні окремі версії цього плагіна (`lampa-aniskip.js`, `player-size.js`, `lampa-mx-mobile-fix.js` і старі об’єднані копії), щоб стара версія не перехоплювала запуск чи не дублювала елементи керування. Потім повністю закрийте й знову відкрийте Lampa.

## Режими відео

- **Заповнити** — відео розтягується на всю висоту через `object-fit: fill`, із чорними полями по 2.5 мм зліва та справа;
- **Вмістити** — увесь кадр із чорними полями;
- **Збільшити 150/170/180%** — плавне масштабування центру кадру;
- **По вертикалі 150/170%** — збільшення по висоті;
- **Кіно 21:9** — відео на всю висоту через `object-fit: fill`, із чорними смугами по 8 мм зліва та справа, як у кіно-режимі на прикладі.

- **Anime4K x2** — обробка кожного кадру через багатопрохідні Anime4K GLSL shaders у WebGL. Відео та звук залишаються штатними для Lampa, а поверх відео виводиться GPU canvas. Якщо WebGL недоступний або shader не компілюється, відео автоматично повертається без апскейла.

За замовчуванням використовується режим **Вмістити**, щоб не розтягувати обличчя та не обрізати важливі частини кадру.

> Аудіо, seek, продовження перегляду та керування залишаються у штатного відео Lampa. Anime4K обробляє лише зображення кадру й не перенаправляє відеопотік.
