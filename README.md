# Lampa Player Size

Зовнішній плагін для Lampa, який додає додаткові режими до меню **«Розмір відео»** без перескладання Lampa.

## AI-покращення якості відео

У єдиний плагін додано локальне WebGPU-покращення для вбудованого HTML5-плеєра. Воно намагається зробити низьку якість відео чіткішою: збільшує кадр на GPU, додає легке адаптивне підвищення різкості та не надсилає відео на сервер.

У верхній частині відео з'явиться повзунок **«Покращення якості»**. Він реально змінює силу обробки: вище значення дає більшу деталізацію, але збільшує навантаження на iPhone. Значення **0%** вимикає AI-обробку. Якщо WebGPU недоступний або GPU не встигає, плагін повертає оригінальне відео автоматично.

Інтеграція використовує легкий WebGPU-підхід із `webvsr`. `flux-fidelity` перевірено як джерело більшого набору рушіїв, але його повний ONNX/RIFE-порт разом із моделями надто важкий для безпечного зовнішнього Lampa-плагіна на iPhone. Тому інтерполяція FPS не видається за вже реалізовану функцію.

## Мобільний фікс для lampa.mx

Окремий плагін `lampa-mx-mobile-fix.js` призначений для вебдодатка `lampa.mx` на iPhone. Він:

- враховує верхню та нижню safe-area iPhone;
- не дає верхній панелі перекривати перший ряд контенту;
- повертає вертикальне гортання Shorts;
- зберігає горизонтальні свайпи в рядах карток.

Посилання для встановлення:

```text
https://cdn.jsdelivr.net/gh/vakdab/Lampa@main/lampa-mx-mobile-fix.js
```

Цей файл потрібно встановлювати **окремо** від плагіна розміру відео.

## Додані режими

- Збільшити 170%
- Збільшити 180%
- По вертикалі 170%
- По вертикалі 180%
- Формат 21:9
- 21:9 без обрізання

## Встановлення

У Lampa відкрийте:

```text
Розширення → Додати плагін
```

і вставте URL:

```text
https://cdn.jsdelivr.net/gh/vakdab/Lampa@main/player-size.js
```

Після завантаження відкрийте плеєр і перейдіть у меню:

```text
Налаштування плеєра → Розмір відео
```

Плагін зберігає вибраний режим у сховищі Lampa та застосовує його до наступних відео.

Режим **«Формат 21:9»** заповнює весь екран у широкому форматі без бічних чорних смуг. Кадр масштабується до розміру екрана, тому на джерелі 16:9 пропорції можуть трохи змінюватися.

Штатний пункт **«Розширити»** перехоплюється плагіном і працює як заповнення екрана з легким розтягуванням по горизонталі. Для штатного пункту **«Заповнити»** залишаються вузькі чорні поля приблизно по 2 мм зліва і справа.

Після виходу з плеєра плагін очищає власні стилі та таймери, щоб верхні елементи Lampa не залишалися поверх головного екрана і не блокували вертикальне гортання Shorts.

## Додати інші режими

Режими знаходяться на початку `player-size.js` у масиві `customModes`. Наприклад:

```js
{
    value: 's200',
    title: 'Збільшити 200%',
    subtitle: 'Збільшити відео на 200%',
    sx: 2.00,
    sy: 2.00
}
```
